# The Latitude

The official website for **The Latitude**, built and maintained by Jude Craig, a member of the band.

## Purpose

The site is a home for the band online — sharing news and releases (like the "Fever Dreaming" single), linking out to where fans can stream the music (Spotify, Apple Music, YouTube), and eventually listing gigs and social channels.

## Built with

The site is built with [Expo](https://expo.dev) (SDK 56) and Expo Router, using React Native so the same codebase can target web, iOS, and Android.

## Running it

Install dependencies:

```bash
npm install
```

Start the app:

```bash
npm start
```

Or run it directly on a specific platform:

```bash
npm run web
npm run ios
npm run android
```
